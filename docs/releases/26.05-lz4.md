7-Zip LZ4 26.05.3：新增原生“智能解压至此”。

- 包内只有一个共同的顶层文件夹：直接得到该文件夹。
- 单个或多个散文件、多个顶层目录及混合结构：创建压缩包同名文件夹。
- 自动解开压缩流和 TAR 两层，支持 `.tar.gz`、`.tar.bz2`、`.tar.xz`、`.tar.lzma`、`.tar.lz4` 及常用别名。
- 已有目标目录、文件或链接保持原样；容器重名时创建 `名称 (2)` 等新目录。
- 在资源管理器和 7-Zip 文件列表右键选择 **7-Zip → 智能解压至此**；可在右键菜单设置中停用。
- 命令行：`7zz x -smart bundle.tar.gz -ooutput`。原有解压命令保持原行为。
- 保留官方 93 个语言资源、完整 LZ4 功能和多语言安装器。新菜单文字提供英、简中、繁中和德语。

下载：

- `7z-lz4-26.05.3-x64-setup.exe`：Windows x64 安装版，需要管理员权限，支持从 26.05.2 升级。
- `7zip-26.05.3-lz4-windows-x64.zip`：Windows x64 便携版。
- `7zip-26.05.3-lz4-linux-x64.tar.gz`：Linux x64 命令行版。
- `7zip-26.05.3-lz4-source.tar.gz`：对应源码、语言资源、安装和验证脚本。
- `SHA256SUMS.txt`：以上四个文件的 SHA-256 校验和。

双层解压使用临时磁盘空间，不在目标目录留下中间 TAR。不会无限递归解开 ZIP/7z 内的其他归档文件。详细目录规则、限制和验证说明见 `docs/smart-extract.md`；历史见 `CHANGELOG.txt`。

Windows 安装包未签名。升级时不会关闭资源管理器；若 DLL 被占用，按提示重启完成替换。Windows 11 原生菜单可能位于“显示更多选项”。旧 MiMo 26.04.2 仍需先卸载再安装。本定制版与官方 7-Zip 共用 shell CLSID，一次由一个安装目录拥有右键集成。
