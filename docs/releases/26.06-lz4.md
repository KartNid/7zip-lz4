7-Zip LZ4 26.06.1：合并官方 7-Zip 26.06，并保留全部定制功能。

- 完整合并上游提交 `d3296e39e1f1f92c7b41c0c3848e65640428d42d`，程序内核版本更新为 26.06。
- 纳入官方改进：Linux `split` 分卷命名支持，以及错误和漏洞修复。
- 保留标准 `.lz4`、7z 内 LZ4 压缩和解压。
- 保留“智能解压至此”：自动处理压缩 TAR 两层、复用同名文件夹，以及跳过、覆盖、重命名和“应用到全部文件”。
- 保留 93 个官方语言资源、定制界面翻译、多语言安装器及原生右键菜单。
- 新增分卷命名和后缀扩展、分卷 ZIP、CAB/MSZIP、SZDD 及归档更新回归测试；继续运行 LZ4、智能解压、安装和原生 Windows 界面测试。
