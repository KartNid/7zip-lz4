## 重点检查

- 分卷：新的 `CSplitVolName` 供分卷处理器和文件管理器合并功能共用，支持普通数字、字母及 Linux 自动增加后缀长度的命名。分卷流支持内部 ZIP 等格式的随机读取。
- 复制流：上游拆出 `CCopyCoderBase`，并调整归档更新调用。本项目的 LZ4 处理器仍使用兼容的流辅助接口，不依赖已移除的实现成员。
- TAR 和其他归档：检查了输出流在操作完成回调之前关闭的调整，以及 TAR 目录条目处理；继续通过压缩 TAR、同名目录合并、文件冲突和临时文件清理测试验证智能解压。
- 解码器：纳入 CAB 头部、文件名和边界检查，SZDD 解码和初始字典处理，Deflate/LZX 历史状态初始化、Quantum 参数检查及 RAR3 输入异常处理等上游改动。
- 文件系统和构建：纳入 POSIX 文件名提取修复、macOS 构建参数及手动构建工作流。现有正式发布仍提供 Windows x64 和 Linux x64。
- 语言：继续使用已校验的官方 26.05 语言资源和原有归属记录（`docs/languages.json`）；定制菜单及冲突对话框文字保持独立，未改写语言资源来源版本。
